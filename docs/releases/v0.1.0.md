# Paperboy v0.1.0

Released 2026-10-29. Status: alpha. This is the first public cut of the open engine.

Paperboy reads your Google Search Console, picks what to write from your own data, researches and writes it, fact-checks every claim against the sources that were read, publishes it, and measures what happens next. This release puts that loop, a self-host server and a CLI in one repository under AGPL-3.0.

## Highlights

- **The full loop is open.** Topic selection with a SERP-strength gate, research, writing, the fact check, publishing, Search Console sync and the rank loop.
- **A fact check you can read.** Rule checks first (numbers must appear in the cited source, links must point at pages that were read, banned claims are matched exactly), then a judge. Every article ends in VERIFIED or HELD with the quoted sentence, the problem and the fix. A held article gets one rewrite, then it is checked again, and if it still fails it is not published.
- **One-command self-host.** Docker Compose starts Postgres, a migration job, the API server and a worker.
- **A CLI that agents can drive.** `paperboy` has seven commands and a stable `--json` mode, and `paperboy check` exits 1 on a failed check so it works in CI.
- **Hard cost caps.** An article that would cross 6 web searches, 1.50 USD or 600,000 tokens (defaults in `packages/engine/src/config/models.ts`) is stopped and held for review.

## What is included

| Package or path | Contents |
|---|---|
| `packages/engine` | Topic selection and the SERP-strength gate, research, writing, the fact check (`ruleChecks`, the `Judge` interface, `RuleJudge`, `FastModelJudge`, the optional `HostedVerifier`), publish adapters (WordPress, Ghost, signed webhook), Search Console sync, the rank loop, the self-host REST API server (`src/server/server.ts`) and worker (`src/server/worker.ts`). |
| `packages/db` | 14 Postgres migrations and the runner (`migrate.mjs`). A test applies every migration to a fresh in-memory Postgres (PGlite) on each run. |
| `packages/cli` | `@paperboyseo/cli`: `connect`, `topics`, `write`, `check`, `publish`, `status`, `report`. Zero runtime dependencies, Node 22 or newer. Installs the `paperboy` command (also `paperboy-seo`). |
| `docker-compose.yml`, `Dockerfile` | `db`, `migrate`, `web` (port 3000) and `worker` services. |
| `docs/` | Self-host guide, fact-check method, REST API, MCP plan. |

Database note: the hosted product had two migrations sharing a number. They are now `0011` and `0012`, in one clean sequence.

## Known limits

- **Alpha.** Expect rough edges, and expect the API and schema to change before 1.0.
- **The CLI is not on npm yet.** Run it from source (see below). Do not use `npx paperboy`: the unscoped npm package of that name is a different project.
- **No MCP server in this repository.** The hosted cloud runs one at `https://paperboyseo.com/mcp` (docs: https://paperboyseo.com/docs/mcp). For a self-host, call the CLI with `--json` or the REST API. The planned open server is specified in [docs/mcp.md](../mcp.md). Agent plugins are not shipped yet.
- **No web app in this repository.** The hosted blog on a subdomain and the paste-in prompt feed need it, so those two publish adapters exist in `src/lib/publish` but have nothing to serve them on a plain self-host. Use WordPress, Ghost or the webhook.
- **Baseline fact check on self-host.** The calibrated verifier, cross-site learning and billing are closed and only in the cloud. Self-host uses the open `RuleJudge`, or Claude with your own key.
- **Writing uses Claude and its web search tool.** There is no model-agnostic layer yet.
- **Search Console needs your own Google OAuth client** on a self-host (scope `webmasters.readonly`).
- **CI workflows are parked in `ci-workflows/`** and are not active yet, so pull requests are not checked automatically. Run `npm run typecheck`, `npm test` and `npm run scrub` locally.

## Install

Self-host:

```bash
git clone https://github.com/gleason24-sketch/paperboy.git
cd paperboy
cp .env.example .env  # set ANTHROPIC_API_KEY, the passwords, PAPERBOY_ADMIN_EMAIL, PAPERBOY_ADMIN_PASSWORD
docker compose up --build
```

CLI from source (Node 22 or newer):

```bash
npm ci --prefix packages/cli && npm run build --prefix packages/cli
alias paperboy="node $PWD/packages/cli/dist/cli.js"
paperboy connect https://your-site.com --self-host http://localhost:3000
```

Details: [docs/self-host.md](../self-host.md).

## Upgrade

There is nothing to upgrade from: this is the first release. For later releases:

```bash
git pull
docker compose up --build -d   # the migrate job applies new migrations
docker compose exec db pg_dump -U postgres paperboy > backup.sql   # take a backup before you upgrade
```
